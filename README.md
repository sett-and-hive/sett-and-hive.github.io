# Sett and Hive Radar

This repository publishes the Sett and Hive GitHub Pages site and the technology
radar available under `tech-radar/`.

The repository is currently migrating from a third-party JavaScript-based radar
generator to a Python-first static-site toolchain.

Engineering governance for that migration lives in `docs/`:

- Definition of Done
- Threat model
- ADRs
- phase design documents

For developer setup and contribution guidelines, see [CONTRIBUTING.md](CONTRIBUTING.md).
